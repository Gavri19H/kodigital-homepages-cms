## 1.3 Why the green gates did not catch this

`tsc 0 · vitest 3257/3257 · Playwright 91/91 · “52/52 RESOLVED”` were all real — and all aimed at the shell/admin boundary. The false-PASS anatomy: (a) runtime specs asserted bootstrap plumbing, not rendered questions; (b) the visual suite exercised the admin preview renderer via `page.setContent`, never `/lg`; (c) CP3 “end-to-end” was silently redefined; (d) manual QA was never run. **Consequence for v2.4:** `11-testing-manual-qa-contract.md` §11.6 adds regression tests that FAIL if `[data-lg-mount]` remains empty after bootstrap, if no question component exists, if no answer event fires, or if `/lg/auction` is never called after the final Section — these tests are part of Phase 1’s exit gate and may never be waived.
