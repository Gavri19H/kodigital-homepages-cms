## 1.2 Failure statements (operator-visible, each traced in `17`)

- **F1 Duplicate headline** — headline/subheadline typed twice (top form + canvas component); the two copies render differently in preview vs runtime. *(3.1)*
- **F2 Scope-blind inspector** — code-ish labels, no indication whether an edit hits the component, the slide, or the page. *(3.2)*
- **F3 Hex-first color UX** — raw hex in dropdown labels AND in stored override values; free-text preset names. *(3.3)*
- **F4 Wrong layout mental model** — page chrome inserted per Section from the "Layout"/"Navigation" groups. *(3.4)*
- **F5 Missing canvas toolbar** — 8-button reorder strip instead of a professional context toolbar; no undo/redo. *(3.5)*
- **F6 Shallow cards** — image/icon cards can't carry alt/title/subtitle/badge/states or a per-card mapping shortcut. *(3.6)*
- **F7 Technical component picker** — thumbnails exist (v2.4), but grouping/wording still exposes internals and mixes frame chrome into unit groups. *(3.7)*
- **F8 Pattern ceiling** — the A–E capability patterns cannot be produced without abusing per-Section chrome. *(3.8, §10)*
- **F9 Under-modeled Quote Builder** — no frame, theme, branding, or real preview. *(3.9)*
- **F10 Manual logo** — no site inheritance; logo placed by hand. *(3.10)*
- **F11–F13 Progress/back/footer per-slide** — funnel-level concerns authored per Section. *(3.11–3.13)*
- **F14 Continue ownership unclear** — Section `continue_mode` exists, but no frame-level default placement/style. *(3.14)*

## 1.3 Root cause

v2.4 Q4 scoped layout containers INTO the Section canvas (v2.4 08 §8.5) because no frame entity existed to receive them. That was the right call to unblock patterns then; v2.5 creates the missing entity (frame + theme on the Funnel) and **AMENDS v2.4 08 §8.3/§8.5**: page-scope items move out of the Section palette (`08 §8.2`), while their renderers are preserved and reused by the frame.
