## Codebase Patterns
- Worker package lives under `api/` (separate from repo root); `api/package.json` carries all worker scripts (dev/test/typecheck/verify/db:migrate/deploy).
- Use `tsx` to run TypeScript scripts (e.g., verify scripts) without a build step.
- `compatibility_date` for wrangler is mission-pinned ("2026-05-06") — do not bump silently.
- Banned legacy production identifiers (must NOT appear in active code/config): `theiwise.com`, `a2z-cf-cms-v1-api`, `a2z-cf-cms-v1-db`, `insureprimo`, `quotesRoutes`, `psychic-quiz`, `rental-booking`. - Verify script must self-exclude and exclude legacy reference docs (docs/source-architecture.md, docs/no-touch-red-line.md, docs/reference/current-theiwise-technical-spec.md).

- **Learnings for future iterations:**
  - `@cloudflare/workers-types` types `FormData.get(name)` as `string | null` even though the Workers runtime returns `File` objects for multipart file fields. Cast through `unknown` (`form.get("file") as unknown as File | string | null`) before `instanceof File` narrowing — without the cast, TypeScript flags the `instanceof` as TS2358 because `string` can't be on the LHS of an instanceof check. UUID-prefixed keys make the contract trivially correct.
  - In Workers tests, `Uint8Array` and `Uint8Array.buffer` (`ArrayBufferLike`) are NOT interchangeable for type purposes since TS 5.x — `ArrayBufferLike` includes `SharedArrayBuffer` which is not assignable to `ArrayBuffer`. Keep test fixtures as `Uint8Array` and have your mock's `put` normalize via a `toBytes(value: unknown): Uint8Array` helper rather than narrowing `value: ArrayBuffer | Uint8Array` (the union widening bites you on `.buffer` access).
  - `fileEntry instanceof File` after the `as unknown as File | string | null` cast is enough to narrow on the value side: in @cloudflare/workers-types `File extends Blob` is declared as a class, not a type alias, so the runtime check works. Don't be tempted to substitute `"arrayBuffer" in fileEntry` duck-typing — File is a real class in the Workers runtime and the instanceof check is the cheapest correct discriminator.
