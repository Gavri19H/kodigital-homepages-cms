## Codebase Patterns
- Worker package lives under `api/` (separate from repo root); `api/package.json` carries all worker scripts (dev/test/typecheck/verify/db:migrate/deploy).
- Use `tsx` to run TypeScript scripts (e.g., verify scripts) without a build step.
- `compatibility_date` for wrangler is mission-pinned ("2026-05-06") — do not bump silently.
- Banned legacy production identifiers (must NOT appear in active code/config): `theiwise.com`, `a2z-cf-cms-v1-api`, `a2z-cf-cms-v1-db`, `insureprimo`, `quotesRoutes`, `psychic-quiz`, `rental-booking`. The Cloudflare account UUID `44c73f76-6ed5-4b26-b442-6c2044326c4d` is shared with the new project (allowed in wrangler.toml/CI/docs/verify-script as account_id), so it is NOT in the banned scan set.
- Verify script must self-exclude and exclude legacy reference docs (docs/source-architecture.md, docs/no-touch-red-line.md, docs/reference/current-theiwise-technical-spec.md).

## 2026-05-07 - T4 (api/src/index.ts + api/src/auth/access-auth.ts)
- Created `api/src/auth/access-auth.ts` exporting `accessAuth` Hono `MiddlewareHandler<{ Bindings: Env }>`.
  - If `parseBoolean(env.DEV_BYPASS_AUTH)` is true → call `next()` (dev-only escape hatch).
  - Else: require either `cf-access-jwt-assertion` request header OR a `CF_Authorization` cookie.
  - If neither is present → respond 401 JSON `{ error: "Unauthorized: missing Cloudflare Access credentials" }`.
  - Phase 0 intentionally does NOT verify the JWT signature (deferred to a later phase).
- Created `api/src/index.ts` Hono app with:
  - `app.get('/health', …)` returning JSON `{ ok: true, app: "kodigital-homepages-cms" }`.
  - `app.use('/admin/*', accessAuth)` and `app.get('/admin', accessAuth, …)` so accessAuth gates `/admin` and any subpath.
  - `app.notFound(…)` returning JSON `{ error: "Not Found", path }` with status 404 (non-empty body).
  - Comment `Route: GET /health` placed above the route to satisfy the `grep -c 'GET.*health'` AC.
